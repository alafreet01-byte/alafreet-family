# ALAFREET FAMILY V10

نسخة محلية مستقرة ومنظمة من تطبيق العائلة.

## التشغيل
1. فك الضغط.
2. افتح المجلد الذي يحتوي على `package.json` في VS Code.
3. افتح Terminal واكتب:

```bash
npm install
npm run dev
```

4. افتح: `http://localhost:3000`

## أهم الروابط
- `/dashboard` لوحة التحكم
- `/showcase` وضع العرض
- `/family` أفراد العائلة
- `/chat` المحادثة
- `/calendar` التقويم
- `/memories` الذكريات
- `/tasks` المهام
- `/rewards` المكافآت
- `/assistant` المساعد التجريبي
